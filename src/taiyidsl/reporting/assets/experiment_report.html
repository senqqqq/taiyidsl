Phase and carrier reference

__PHASE_REFERENCE__ shift_phase(θ) adds θ to F, and Rz(θ) subtracts θ. reset_frame clears F while preserving carrier evolution and inherited modulation. reset_phase also clears inherited modulation and sets the carrier origin to that instant. The accumulated Rz value records provenance and its contribution is already included in F.

θ(t) = Φ_osc(t) + s[F(t) + φ_pulse(t)]. Φ_osc includes carrier evolution, inherited modulation, mapping offsets and calibration. φ_pulse includes the gate's base phase and local modulation. Epoch mode uses the current frequency and selected carrier origin. Continuous mode integrates the actual frequency history. Carry mode inherits the analytic terminal modulation. The carrier reference persists across Section, chunk, segment and tile boundaries. Each group and gate lists its reference time. start_phase_deg is the phase at the first sample, including accrued carrier phase. Table times are relative to logical T0. The pulse sheet can also display physical preparation time.
